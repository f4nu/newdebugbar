# New Debug Bar

New Debug Bar is a modern, Laravel-only debug bar built with Livewire 4 and Tailwind CSS 4.

The package is under active local development. Its first host application is Vite Clinic Core.

## Local development

```bash
composer install
npm install
npm run build
composer test
```

The package is local-only and must be installed through Composer’s `require-dev` section.
