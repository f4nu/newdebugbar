# Changelog

All notable changes to New Debug Bar are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## Unreleased

## 0.1.0 - 2026-08-02

- Added the package-owned bottom toolbar and inspector in light, dark, and system themes.
- Added Laravel request, query, Livewire, model, cache, view, event, log, exception, outbound HTTP, queue, mail, notification, and Redis profiling.
- Added retained profile history, route comparison, a relative timeline, and deterministic findings.
- Added first-class Artisan, test-command, and queue-worker profiles.
- Added four bounded, read-only tools through Laravel's first-party local MCP server.
- Added shared test assertions, strict redaction, atomic local storage, and package-owned compiled assets.
